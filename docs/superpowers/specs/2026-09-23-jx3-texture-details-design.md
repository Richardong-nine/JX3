# 剑网3 130级纪念站纹路细节增强设计

## 目标

在不改变现有页面结构、人物顺序和纯纵向滚动体验的前提下，增加具有剑网3江湖气质的纹理、阵纹、金属蚀刻边框与轻微动态光效，让页面更精致、更有层次，同时确保角色图片和姓名仍然是视觉中心。

## 视觉方向

采用“古卷阵纹 + 金属蚀刻”的中等强度方案：

- 全局增加低透明度经纬网、斜向刀刻纹和边缘暗角。
- 开场使用大型同心阵环、方位刻度和缓慢呼吸的暗金光晕。
- 合影区域增加山河等高线式圆纹与四角框线。
- 人物章节使用章节编号横线、细密斜纹和影像框角刻线。
- 情侣章节使用左右对称的同心纹与连接印记，强化“双人共同章节”。
- 终章以收束式圆阵和淡金边纹呼应开场。

## 动效与性能

- 纹路只使用 CSS 渐变、伪元素和现有滚动进度变量，不引入额外图片或第三方库。
- 动效保持缓慢、低透明度，不干扰阅读。
- `prefers-reduced-motion` 下停止纹理漂移和呼吸动画。
- 760px 以下降低纹理密度并隐藏非关键装饰，避免移动端画面拥挤。

## 验收标准

1. 开场、合影、人物章节、情侣章节和终章都有可辨识但克制的纹路细节。
2. 人物图片、角色名、门派和简介的可读性不下降。
3. 页面仍只需上下滑动，没有新增进入式交互。
4. 移动端布局不横向溢出。
5. 全部自动化测试通过，并新增纹理系统的样式契约测试。
