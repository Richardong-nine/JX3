# JX3 江湖残影动效设计

## 目标

为每个角色增加随章节滚动收束的黑灰与朱红双重残影，强化“旧影归位、故人重现”的纪念感，同时保持页面只有上下滚动、不增加点击进入或循环抖动。

## 动效结构

- 每张角色图增加两张仅用于装饰的同源副本：墨影与朱影。
- 角色进入当前滚动步时，墨影由外侧、朱影由另一侧错位出现，随后向原图收束。
- 本体图在收束过程中由暗到明；末段残影淡出，本体保持稳定。
- 双人章节采用镜像方向：左侧人物残影从左侧归位，右侧人物残影从右侧归位。
- 末段增加一条克制的金色扫描光，不遮挡角色名与正文。

## 图像与混合方式

现有角色图包含黑色背景，因此不使用 `brightness(0)` 制作整块黑矩形。残影通过滤镜配色并使用 `mix-blend-mode: screen`，让黑色背景接近不可见，只保留人物亮部轮廓。

## 降级策略

- JavaScript 未执行时，本体图默认完整显示，残影默认隐藏。
- 移动端隐藏墨影，仅保留较轻的朱影，降低视觉拥挤与渲染压力。
- `prefers-reduced-motion: reduce` 下隐藏全部残影与扫描层，并直接显示本体。
